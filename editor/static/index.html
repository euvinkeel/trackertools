Keyboard & mouse

← →
Previous / next frame (Shift ×10, Alt 1 second)
Space
Play / pause
Home End
First / last frame
G
Go: track every tracker that needs it, from the cursor / Halt
Shift+G
Track only the selected trackers (or the selected subject's)
Drag on frame
Box-select trackers · Ctrl+click adds/removes one · A selects the subject's trackers · Esc clears
Ctrl+drag
End the selected subject's trackers inside the box from this frame on (Ctrl+Alt+drag: outside)
Shift+drag
Draw a template box around a pattern; paint the mask and set a hotspot. With a template tracker selected, adds another look.
Drag subject ring
Offset the subject from the position its trackers pushed it to (auto-keys this frame) · [ ] jump offset keys
N
New subject
1–9
Select subject
Click frame
Add a CoTracker point to the selected subject on this frame (outside the frame → manual point)
Drag tracker
Move it: keyframe (manual) or re-anchor (auto); dragging off-frame switches to manual
Double-click tracker
End it from this frame on (deletes on its first frame)
M
Toggle manual animation for the selected tracker(s) from this frame
E
End selected tracker(s) here (later keys, ranges and results are retained)
U
Remove the end(s) of the selected tracker(s) — an automatic end stays off until re-enabled
Drag the timeline end marker
Move a tracker's end; Del/Backspace with the marker focused removes it (the tracker stays)
B
Bounds mode: move/resize the manual layer (changes fade over ±falloff; Alt+wheel adjusts), or draw one
P
Puppeteer pass: follow the subject at slowed playback; each pass is kept (refine levels, + Take averages). Esc/Space/click stops
R
Finetune layers: drag relatively to nudge the active layer (Shift 1/10, Q loupe, ← → step and hold)
Shift+drag
Draw a template box; paint the mask/hotspot and optionally Save to library for reuse in any video
Patterns list
Use adds a saved pattern to the selected template tracker (or starts a new tracker); Export/Import shares the library
Automatic ending
Sidebar → subject: end trackers after a sustained escape from the bounds, or after motion disagreement (reversible)
Del
Delete selected tracker(s) entirely
[ ]
Jump to previous / next keyframe of the selected tracker (or offset key of the subject)
Ctrl+Z
Undo (Ctrl+Shift+Z redo)
Viewer wheel
Zoom at mouse · middle/right-drag or Space+drag to pan · F fit
Timeline wheel
Zoom at mouse · Shift+wheel pan · wheel over names scrolls · \ fit

Template tracker

Red pixels are excluded. An empty mask tracks the whole box. Right-click paints with the eraser. The hotspot snaps to pixel corners and centers; hold Shift to place it freely.
